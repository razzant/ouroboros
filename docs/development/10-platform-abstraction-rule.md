# Platform Abstraction Rule

Use `platform_layer.py`, with `platform_win32_abi.py` (Win32 ABI), `platform_darwin_abi.py` (macOS kernel birth for `process_identity.py`) and `platform_peer.py` (peer lookup).

Modules (`fcntl`, `resource`, `grp`, `pwd`, `msvcrt`, `winreg`, `ctypes.windll`), `os.kill`/`os.killpg`/`os.setsid`/`os.getpgid`, `signal.SIGKILL`/`signal.SIGTERM` and platform-conditional subprocess flags (`subprocess_new_group_kwargs()`/`subprocess_hidden_kwargs()`) go through the layer; paths use `pathlib.Path`, no hardcoded separators. Owners re-point kept host paths (skill venv, CLI link, sign-in entry, dependency receipt); no tracked name is application-typed (`tests/test_no_application_names.py`); trees that may hold one (bytecode mirror, safe_test roots) are born `.noindex`, unlike kept work (projects, Deliverables, uploads, task results). Platform-guarded function-local exceptions: `resource` in `extension_process_runner.py`, `winreg` in `windows_autostart.py`, `msvcrt`/kernel32/ntdll in `confined_files.py`, `fcntl`/`msvcrt`/`_winapi`/kernel32 in `body_switch.py` (stdlib-only), typed `ctypes` caption calls in `launcher_appearance.py` (one window's `before_show` handle, UI-thread `BeginInvoke` and close, which no generic wrapper owns), `ctypes` and direct `CREATE_NO_WINDOW` in `launcher_windows_runtime.py` (stdlib-only pre-import repair), `ctypes`/`fcntl`/`msvcrt` for clones and transparent compression in `artifact_storage.py` (APFS `clonefile`/`ditto`, Linux `FICLONE`, NTFS `DeviceIoControl`; best effort), and child-local `ctypes` I/O priority in `storage.py` (`setiopolicy_np`, `ioprio_set`, Windows background mode; reported, best effort). Exceptions remain reviewable.

Enforcement: `tests/test_platform_guard.py` scans native APIs, launcher subprocess flags and detachment. `tests/test_launcher_source_handoff.py` covers hidden GUI spawns, inherited CLI consoles and pre-import PyInstaller GUI provenance/sole visible console. Seed argv alone never detaches. Launcher unit tests must use dead ports and keep the independent HTTP/socket refusal in `tests/launcher_network_guard.py`; swallowed attempts fail teardown. Other flags: review, `cross_platform`.

### Shared state-file helpers

Use `ouroboros/utils.py` for durable files: `atomic_write_json`/`read_json_dict`, `write_text_atomic`/`write_bytes_atomic`. Full overwrites are byte-exact and crash-atomic; `fsync` is opt-in, appends non-atomic. Prefer these to bare `Path` writes; lockfiles go through `platform_layer.acquire_exclusive_file_lock`/`release_exclusive_file_lock`, except never-unlinked lifetime holds (the PID lock, `server_entrypoint.admit_data_root`). Narrow exceptions: `supervisor/state.py` keeps `atomic_write_text` for its mirrored state writes and `config.py` its own settings-file lock: settings load before the shared helpers. Enforcement: `tests/test_atomic_write_v639.py`; the prefer-the-helper rule is review-only.
