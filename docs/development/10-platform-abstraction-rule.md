# Platform Abstraction Rule

Use `platform_layer.py`: `platform_{win32,darwin}_abi.py` (native ABI), `platform_peer.py` (peers), `platform_process_target.py` (held targets).

Modules (`fcntl`, `resource`, `grp`, `pwd`, `msvcrt`, `winreg`, `ctypes.windll`), `os.kill`/`os.killpg`/`os.setsid`/`os.getpgid`, `signal.SIGKILL`/`signal.SIGTERM`, platform subprocess flags (`subprocess_new_group_kwargs()`/`subprocess_hidden_kwargs()`) use the layer; paths use `pathlib.Path`, no hardcoded separators. Owners re-point kept host paths (skill venv, CLI link, sign-in entry, dependency receipt); no tracked name is application-typed (`tests/test_no_application_names.py`); trees that may hold one (bytecode mirror, safe_test roots) are born `.noindex`, unlike kept work (projects, Deliverables, uploads, task results). Platform-guarded function-local exceptions: `resource` (`extension_process_runner.py`, `llm_observability.py`), `winreg` (`windows_autostart.py`), `msvcrt`/kernel32/ntdll (`confined_files.py`), `fcntl`/`msvcrt`/`_winapi`/kernel32 (`body_switch.py`, stdlib-only), typed `ctypes` caption/`winreg` app mode (`launcher_appearance.py`: one window's `before_show` handle, UI-thread `BeginInvoke`, close; WebView2's rule), direct `CREATE_NO_WINDOW` (`launcher_windows_runtime.py`: stdlib-only pre-import repair, plus `winreg`/`ctypes`; `git_selection.py`: stdlib-only, imported by `platform_layer.py`), `ctypes`/`fcntl`/`msvcrt` clones/transparent compression (`artifact_storage.py`: APFS `clonefile`/`ditto`, Linux `FICLONE`, NTFS `DeviceIoControl`; best effort), child-local `ctypes` I/O priority (`storage.py`: `setiopolicy_np`, `ioprio_set`, Windows background mode; reported, best effort); all reviewable.

Enforcement: `tests/test_platform_guard.py` (native APIs, launcher subprocess flags, detachment), `tests/test_launcher_source_handoff.py` (hidden GUI spawns, inherited CLI consoles, PyInstaller pre-import GUI/console; seed argv never detaches), and `tests/launcher_network_guard.py` (launcher unit tests must use dead ports and keep its independent HTTP/socket refusal; swallowed attempts fail teardown). Other flags: review, `cross_platform`.

### Shared state-file helpers

Prefer `ouroboros/utils.py` over bare `Path` writes (review-only): `atomic_write_json`/`read_json_dict`, `write_text_atomic`/`write_bytes_atomic` enforce byte-exact crash-atomic overwrites, opt-in `fsync`, non-atomic append. Use `platform_layer.acquire_exclusive_file_lock`/`release_exclusive_file_lock` except never-unlinked lifetime holds (PID lock, `server_entrypoint.admit_data_root`). `supervisor/state.py` keeps `atomic_write_text` for mirrored state; `config.py` locks early settings before helpers load. Registry publication: `platform_file_rename.rename_exclusive` for no-replace/exchange; certificate lock (PERSISTENCE).
