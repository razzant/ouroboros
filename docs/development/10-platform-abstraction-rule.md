# Platform Abstraction Rule

Use `ouroboros/platform_layer.py`, with `platform_win32_abi.py` (Win32 ABI), `platform_darwin_abi.py` (macOS kernel birth for `process_identity.py`) and `platform_peer.py` (peer lookup). Exceptions follow; shared atomic helpers preserve durable bytes across OSes.

Modules (`fcntl`, `resource`, `grp`, `pwd`, `msvcrt`, `winreg`, `ctypes.windll`), `os.kill`/`os.killpg`/`os.setsid`/`os.getpgid`, `signal.SIGKILL`/`signal.SIGTERM` and platform-conditional subprocess flags (`subprocess_new_group_kwargs()` / `subprocess_hidden_kwargs()`) go through the layer; paths use `pathlib.Path`, never hardcoded separators. Platform-guarded function-local exceptions: `resource` in `ouroboros/extension_process_runner.py`, `winreg` in `ouroboros/windows_autostart.py`, `msvcrt`/kernel32/ntdll in `ouroboros/confined_files.py`, `fcntl`/`msvcrt`/`_winapi`/kernel32/`os.kill` in `ouroboros/body_switch.py`, `fcntl`/`os.setsid` in `ouroboros/app_install.py` (captured; stdlib), typed `ctypes` caption calls in `ouroboros/launcher_appearance.py` (one window's `before_show` handle, UI-thread `BeginInvoke` and close, which no generic wrapper owns), `ctypes` and direct `CREATE_NO_WINDOW` in `ouroboros/launcher_windows_runtime.py` (stdlib-only pre-import repair), `ctypes`/`fcntl`/`msvcrt` for clones and transparent compression in `ouroboros/artifact_storage.py` (APFS `clonefile`/`ditto`, Linux `FICLONE`, NTFS `DeviceIoControl`; best effort), and child-local `ctypes` I/O priority in `ouroboros/storage.py` (`setiopolicy_np`, `ioprio_set`, Windows background mode; reported, best effort). Exceptions remain reviewable.

Enforcement: `tests/test_platform_guard.py` scans native APIs, launcher subprocess flags and detachment. `tests/test_launcher_source_handoff.py` covers hidden GUI spawns, inherited CLI consoles and pre-import PyInstaller GUI provenance/sole visible console. Seed argv alone never detaches. Launcher unit tests must use dead ports and keep the independent HTTP/socket refusal in `tests/launcher_network_guard.py`; swallowed attempts fail teardown. Other flags: review, `cross_platform`.

### Shared state-file helpers

Use `ouroboros/utils.py` for durable files: `atomic_write_json` / `read_json_dict`, `write_text_atomic` / `write_bytes_atomic`. Full overwrites preserve exact bytes/newlines and expose complete old or new content across crashes; `fsync` is opt-in, appends non-atomic. Prefer these to bare `Path` writes; lockfiles go through `platform_layer.acquire_exclusive_file_lock` / `release_exclusive_file_lock`, except never-unlinked lifetime holds (the PID lock, `server_entrypoint.admit_data_root`). Narrow exceptions: `supervisor/state.py` keeps `atomic_write_text` for its mirrored state writes, and `ouroboros/config.py` keeps its own settings-file lock, because settings are bootstrapped before the shared helpers may depend on them. Enforcement: `tests/test_atomic_write_v639.py`; the prefer-the-helper rule is review-only.
