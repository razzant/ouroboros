# 6.5 Agent Core — Planning, Memory, Skills & External Tools

This part gives me planning (`plan_task` councils), deep self-review, post-task synthesis, Project rooms and placement (`move_to_project`, `start_task`), durable memory (`memory_read`, `chronicle_write`, `knowledge_list`, `knowledge_read`, `knowledge_write`, `update_scratchpad`), installed skills and extensions (gates: §13), and MCP and browser tools (`call_mcp_tool`, `browse_page`, `browser_action`). ### Planning, deep review, post-task work, memory

Plan review, result review, commit review and deep self-review weigh an intention, delivered result, staged self-change and whole system independently; none inherits another's authority, and post-task work/memory record execution without approving any of them.

#### Plan construction and review

`plan_task` (`tools/plan_review.py`) is the sole planning organ (P3): a reviewer conversation, never a vote; present fields decide the effect. Writing (`goal`, `done_when` `[{id, claim, support}]` in `task_contract` grammar, `affected_paths`, prose `plan`) appends a free revision (carry-over: `plan_review.py` docstring).
