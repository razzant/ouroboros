### Host Service boundary

Host Service (`gateway/host_service.py`, `OUROBOROS_HOST_SERVICE_PORT`) checks `x-skill-token` against payload hash, executable review, enablement, grants and trust via reused discovery (§13; `skill_token.py` keeps tokens secret-free, non-stringified, edit-invalidated; routes/permissions: §4). `host_notify.py` emits signed bounded `skill_notice` events without a model (CREATING_SKILLS "Telling the owner something") and `host_sign_in.py` serves only a skill's own sign-ins (§13). `agent_note.py` gives a program's note a neutral System receipt; `dialogue_provenance` keeps program and owner words apart. Reviewed owner-bound transports may control Ouroboros (`ui_control` marks host-composed commands, not owner words, CLIENT_CONTRACT); external slash commands need `supervisor/state.py`'s positive-owner slot (unidentified senders cannot bind; web identity never excludes the remote owner), and Panic keeps priority over note handling (CLIENT_CONTRACT). `wait_for_response` is A2A-only (CREATING_SKILLS), decision/language writers live in §4, and review waits reach live controllers via `pending_action` (409 on stale revision/identity or absent consumer, §6; verdicts grant no continuation or skill authority).

`host_service._RateLimiter` applies a token bucket to `/ui/ws-message` bursts and sliding windows elsewhere, collapsing refused relays/burst into one `host_service_ws_relay_dropped` row (`logs/events.jsonl`); child `send_ws_message` is best-effort `None` and in-process broadcast unbounded. `chat_uploads.store_upload` (shared with `gateway.files` `/api/chat/upload`) finishes Host-confined multipart spool copies despite HTTP cancel while skills keep sources; neither ingress rejects size (`_INJECT_ATTACHMENT_MAX` and Files policy stay separate), request-local rollback deletes unaccepted copies on partial copy/refusal/cancel so replays never duplicate, and accepted bytes survive disconnect/unknown outcomes without claiming acceptance.

Another installation of my human is a place of the built-in `ouroboros` connector, introduced at both owner doors (`peer_links.py`). It is an agent, never my human: only my human's door sets its two choices, `peer: {mine, may_start}`, and `peer_links.effective_permissions` is the one reading of what the link is given now, for the letter door (`gateway/peer_letters_api.py`) and the place card alike. ### Companion processes
