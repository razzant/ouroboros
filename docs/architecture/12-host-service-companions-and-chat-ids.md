### Host Service boundary

`host_service._RateLimiter` is a token bucket for `/ui/ws-message` bursts and sliding windows elsewhere. Refused relays aggregate per burst into one durable `host_service_ws_relay_dropped` event (count, `logs/events.jsonl`); child `send_ws_message` stays best-effort `None`, in-process broadcast unbounded.

`chat_uploads.store_upload` owns Host-confined paths/completed multipart spools, called by Host Service directly and by `gateway.files` for `/api/chat/upload`. The worker copies and closes its spool despite HTTP cancellation; skills keep sources. Neither ingress rejects size; `_INJECT_ATTACHMENT_MAX` and Files-upload policy stay separate. One request-local cleanup stack removes new unaccepted copies on partial copy/refusal/cancellation; replay adopts no duplicates. Accepted bytes survive disconnect/unknown outcomes, which claim no acceptance.
