# 6.2 Agent Core — Model Calls, Usage & Budget

How I call LLMs across API providers, local models, and caller-owned Claudexor subscriptions, plus how every attempt and dollar is accounted in `state/usage.sqlite`. I can switch models within role bounds (`switch_model`) and inspect live usage and quota facts via `query_data`. Spend tracking never blocks on missing tariffs: unknown cost stays `None` (never zero or a silent veto), while known budget ceilings refuse new paid admission.

### Usage ledger substrate vs. accounting policy

`usage_store.py` owns `state/usage.sqlite`, a row per physical attempt over `store.py` ([Usage store](../USAGE_STORE.md)). `usage_ledger.py` is policy-free; `usage_accounting.py` owns price, holds, settlement, scopes and admission; locking/repair never changes cost. Events, UI and Search (bounded display read) project ledger facts; reviewers count each priced attempt once across retries. Adapters own raw envelopes. `_usage_response` validates reply cash before Chat projection; failed replies reconcile nested bills and wire-ordered reports (a prior stream zero is not a terminal bill); a valid bill, zero included, survives errors without proving completion or authorizing retry, and only evidenced pre-work refusals infer zero. Loop and Safety share `pricing.normalize_usage_cost`: malformed is unknown, absent may be estimated (nonfinal), local is free; Go's route-specific `usage.cost` and tariffs: Usage store.

### Caller-owned subscription model calls

`claudexor::<source>=<model>` selects an owned-engine model operation, not an Agent Run: `LLMClient` routes it through `llm_claudexor.py` before OpenAI-compatible filtering and retries, and Ouroboros owns SYSTEM, BIBLE, messages and tools. Codex exposes raw models; other harnesses keep Agent capabilities, and API keys their routes. `cache_key_for_model` shares the governance prefix across tasks, children and consciousness per data root and model.

`ClaudexorGateway` (`gateways/claudexor.py`) sends idempotent `POST /v2/model-operations`, at most one generation per ID: an unknown outcome or expiry never regenerates, while every further send (a retry, account rotation, served-model redo, redial or the one unsent `auth_changed` reissue per call) is a new operation with a new ID. The CLI refreshes the Agent-shared profile; no relay, copied operator auth or public endpoint. Metadata uses `read_owned_gateway`, sends and lifecycle bounded `ensure_owned_gateway`. Coherent unusable terminals settle, then raise non-repeatable `stream_rejected`; only an exact create `model_request_invalid` proves no admission; received tier refusals settle before a Standard retry; a typed Codex content denial is final. Subscription is not zero; receipts outlive bodies. Images use the selected account’s catalog (§6 Vision). Send drops `stop_reason` and keeps `refusal` as assistant text across cache boundaries; `effort_evidence.py` validates reported tiers without remapping, and Logs separate requested from reported.

When typed facts leave no account for the model, `model_wait.announce_capability_refusal` sends one `model_capability_notice` per mark episode via the terminal outbox.

`model_activity` (`llm_claudexor.py`) reports phases, operation IDs and admission blockers; `loop_llm_call.py` binds `main_llm_call_state`, checked by `supervisor.events`. `context_attempt` carries ledger `physical_context` past the call; `physical_attempt_context.fold_attempt` applies late outcomes to their own identities. Direct calls share `TaskModelWait`; `accepted_operation_scope` excludes helper windows after create; no quota wait or lease changes. `vision_process.py` deduplicates strict `_RECEIPT` identifiers (§3).

#### The live turn slot

Caller-owned `llm_claudexor.ModelTurnState` carries the opaque live-turn token through `LLMClient.chat`, outside history, so neither compaction nor failed bodies rebuild it from old envelopes. A durable result replaces it, `invalid_continuation` repair clears it, other outcomes keep it; one `run_llm_loop` invocation spans rounds, steering, review and quota waits, and the next loop or cold restart starts empty; leaving this transport ends it. Opt-in needs the last successful handshake at `config.CLAUDEXOR_MODEL_TURN_STATE_MIN_VERSION`. The token grants no generation and stays out of usage, events, progress and cards.

#### Roles, accounts and context

`OUROBOROS_MODEL_ACCOUNTS`/`OUROBOROS_MODEL_CONTEXT_WINDOWS` bind roles (§7); equal model names imply no shared role or account. Route keys read the saved document live with `skill_settings` semantics (no mirrored stale key): an unreadable document leaves credentials unavailable; reviewers and actors use route credentials. Auto uses the account's largest advertised window, never CLI compaction thresholds; manual windows assert sizing, not provider or review authority, and capacity, input/output reserve and unknowns stay distinct; usage pairs submitted options with provider echoes, missing keys stay unknown. Account changes reprepare; ordinary, wrap-up and forced-final sends share role and account; headers name the responder. Review `default_temperature` is a route hint; an explicit `temperature`, zero included, may fail. Quota, interruption and unknown custody are no result or verdict. `preferredProfileId` is soft: engine marks outrank it.

#### Configured routes and primary return

`model_slots.route_binding` names model, locality and account or Auto; route choice and handover: `route_choice.py`, `loop_routes.py`. The primary (`route_choice.initial_round_route`) survives a failed fallback, rows saying trying (`model_lane_attempt`). `primary_route_observation.py` renders `[ROUTE FACTS]` once per switch, never rewritten, naming the primary's chooser; changed, dated, non-generating metadata (Claudexor quota too) shares one 3 s budget. Cognition chooses to stay, `switch_model(primary="return")` (the current primary, resuming `held_primary_view`; act logged apart from outcome) or `primary="wait"`. After ordinary 429/503 retries `loop_transport` waits on the primary; only an answer ends waiting, because metadata, clocks and resets prove no generation (P5/P13). Direct API auth/billing waits offer Retry/Switch/Stop, no subscription observer.

`lead_fact.py` publishes `work_lead` (CLIENT_CONTRACT §5); `owner_model.py`/`loop_routes.py` apply durable owner primaries before dispatch (PERSISTENCE).

#### Quota and auth waits

`execution_timeout_sec` / CLI `--execution-timeout` narrows the global ceiling via `model_wait.execution_elapsed_seconds`: queue, confirmed quota, Pause and sleep through Resume consumption are excluded once; tools and result waits count. No time is regranted; `timeout_sec` stays a calendar deadline.

`llm_capability_policy.model_catalog` negotiates `includeAdmission`; `catalog_admits_model` shares exact-model admission across waits and recovery. Advisory absence permits an attempt without inventing a row; older engines keep membership semantics; source/account/fingerprint/freshness checks stay. Failed discovery is not empty success, and admission proves neither generation nor the earlier outcome.

`model_wait.py` holds the live call for quota, auth, dated pools or a gone connection via mailbox and `/api/decisions` `model_wait:<task>:<wait>`. Dated non-mixed pools are `unavailable`, undated refusals use transport recovery, only `poolCause` proves exhaustion; the engine alone places and deprioritises accounts, and pins never rotate. Rows project admission and observed access, not a ledger. Another model's completed answer is retained and ACKed but rejected as the round; `model_substituted` means root fallback or exact-route-child failure, never cooldown. Resource refusals, a gone connection too (`ConnectionUnavailable`, $0, card `connection_unavailable`, never a failure alone), take Auto account rotation first, then the round's other configured routes (§7), and only then an owner wait on the retained refusal, naming needed sign-in; Presence turns and bounded program returns never wait (§12). Temporary switches affect only this wait; Settings, review and task application stay separate; Fallback Local is group-wide.

`gateway/task_model_wait.py` owns effects, `task_decision.answer_decision` serves Web/Host Service, `supervisor/task_model_wait.py` projects worker events and clocks, `gateway/decision_contracts.py` owns decision vocabulary. Worker and project-write ownership stay held (one worker means the queue waits); reviewers keep their operation through settlement (§6 Review stack). Browser closure keeps the wait; process stop ends it. Lost VLM results (`vision_process.py`) stay unknown, never free. Review decisions reach only the exact live `review_operation_controller`, never an ended author's mailbox. Consciousness (`handle_wake_direct`) shares owner-turn registration, model wait, Stop and unknown-outcome recovery.

#### Streams and transport waits

`llm_stream.py` assembles Main remote streams before settlement. Partial answers/calls stay in private CAS (`physical_stream`), never executed. Chat names suppress identical fragments (`a,a` becomes `a`), append others and report both; other deltas stay intact. Receipts name anomalies. After terminal framing, unusable bodies are `stream_rejected` with received usage; unterminated streams are unknown. A typed timeout after output grants configured API children one same-actor repeat (`llm_attempt`), without repair, reroute or summary; `working_checkpoint` saves it, recovery cannot renew it, and `trace_refs.timeout_repeat` lets the parent decide. Unconfirmed dispatch is UNKNOWN. Native `timeout_error` qualifies; managed errors without typed progress do not. Missing final usage means unknown cost; pings set no cognitive deadline; HTTP and logical waits differ.

`loop_transport.py` keeps one recovery episode (rails above); mail can shorten backoff, `place_arrival.wake=false` cannot. Fresh non-generating upstream evidence may admit continuation with `[SYSTEM NOTICE]` (connectivity only); subscription evidence needs `provenance="provider_http"`, `observedAt` after the failure and matching source/model/account, and cache reads never refresh it. Control-link, create, status and result-read failures (generic 404 too) rejoin the same operation or key across endpoint rediscovery, proving no non-dispatch and generating nothing while recoverable.

### Budget tracking

`usage_accounting.py` ([store](../USAGE_STORE.md)) owns `reserved → dispatched → settled | unresolved` transitions and proven-unsent release (dispatched release needs engine no-inference proof; `_usage_wait.py` retries rolled-back contention off locks). Retries get new IDs while unsent preparation keeps identity/custody; prestart Pause saves pixels as `image_source_ref` for verified Resume/restart, which rechecks money/controls; Restart preserves sources and revokes unused grants; unstarted Stop concludes stopped; Panic/deadlines/ceilings bind without an owner. Corruption, permission/resource faults and unknown outcomes never resend. Costs count once, opaque spend stays unknown until receipts arrive, prices/releases are final, and OpenRouter reconciliation is explicit.

`cost_projection.py` ([store](../USAGE_STORE.md)) projects amounts and openness (`accounted_upper_bound_usd` = settled+reserved+unresolved; `COST_OPENNESS_FIELDS`, §11.1; `reconstruct_task_cost` for own cost, terminal/heartbeat/checkpoint/synthesis for root-tree). Missing/unpriced rows stay null/unknown (never $0) and known partial cash proves no bound; pending/live/unrecorded runs hold finality, cleanup does not; `delegated_runs` revisions owe publication (no closed-history replay or new poller); checkpoints own finality (`root_phase_checkpoint.accounting` is observation; `terminal_cost_reconciliation` keeps late rights), and `unknown_unmetered` adds no status. `resource_facts` shares counts/durations/headroom without classifying behavior; `swarm_rollup` folds `swarm_fanouts` over witnessed bases (replaying invalidated bases off-lock, unproven facts unknown) while `swarm_efficiency` infers no waves or wait time.

**Planning threshold** (`task_pacing.py`). One unreserved `CostCeiling` (`disabled`, `active`, `exhausted_soft_land`, `unknown`) drives loop checks and `in_task_cost_ceiling` apart from admission: ordinary tasks have `no_default_cost_stop`, explicit `cost_hard_stop_pct` picks the lesser of global-remainder share and root margin, and producer allowances stop at actual value. Descendants inherit root authority; cold restores keep unreadable policy as `legacy_policy_unverified` rather than widening it.

`loop_budget._check_budget_limits` runs after unfinished spending rounds (never adding a paid final after READY): eligible tasks pause, other actors wrap up paid only when profile and admission fit (`budget_wrapup_unaffordable` otherwise), and producer/unverified limits end unpaid. Unknown price fails open, unknown spend is never zero, affordability probes reserve nothing, and `_usage_cache_splits.py` reuses settled cache ratios. `task_pacing.main_loop_wire_options` owns outgoing shape; pre-send drift refuses `forced_candidate_drift` with one unpredicated terminal retry so answers are not lost.

#### Exact budget pause and Resume

`budget_pause.py` fences pooled/direct work and text Presence, settles producers and parks the same ID on `owner_wait.continuation_state` without a paid final (missing owner/stable save: `exact_pause_unavailable`). Money fences trees (unknown delegated-stop coverage admits no writer); technical pauses park one member (readable authority wakes it by exact grant; unknown legacy needs Resume); confirmed contention retries the same source under ending controls while unknown publication holds.

`work_stop.current_stop` reads installation → tree → member (independent member stops survive tree release); owner/budget fences decide first, then explicit `_budget_pause_hold`, then a live exact/zero-dispatch marker (owner markers without a closed fence await selection; sleep is a wait; `by` owns attribution; point `refusal` keeps Resume visible; release deletes stop and selection so history never restores it).

All Resume doors (`queue_transitions`, `budget_resume`, mind child/Continue selection) read `release_refusal`: Panic holds require the owner, while other stops allow Resume after rechecking source, fresh money, Stop/restart, time and ancestry. Addressed actions repair ended local recipients while live writers refuse with named blockers; no live execution means Paused + Resume, only live execution is Pausing (saved work survives read gaps; sourceless owner seeds keep `unsaved_pause_intent`).

`events_budget` separates cause-free `_resume_selection` from single-use grants: `root_resume_basis` binds actor/grant/fence (not time), consumption keeps the selection without permitting replay, no-fence Resume supersedes bound choices and rebinds unbound ones without reissuing grants, dispatch rechecks root generation, and a new Pause invalidates prior choices (`retain_consumed_selection` keeps lending IDs; `owner_pause.consumed_member_resume` repairs missed selection). `resume_paused_loop` saves unanswered calls, route, attempt, spend and time before consuming the grant; spent/revoked/foreign grants refuse; OS handles never return and only explicit graceful profiles allow a final reservation.

#### The model's own sleep

`await_messages`, `wait_task` and `wait_tasks` sleep by default (saving delivery duties before release; without a continuation owner the default stays in-process); explicit `mode="in_slot"` (`sleep_mode` on task/delegate waits) stays in-process while lending acting capacity (`in_slot_wait`), zero timeout peeks unless sleep sources are named.

`model_sleep.py` runs check → install → recheck over canonical sources (wake sources: its docstring); polls batch typed statuses keeping known readiness on refresh failure; services pin one start (exit code or unknown on loss).

Warm sleep keeps stack, browser, actor and lane via `owner_wait` while lending capacity (§5); cold sleep saves source/attempt/clocks (disclosing browser/REPL loss; owner questions stay warm) and may transfer exact runs via `sleep_custody.py` after dispatch closes. Sleeping parents never stop children; leases, Pause, money and Stop still bind. `continue_in_background(reason)` parks a conversation turn into the project pool with the same ceilings and run transfer (refusing services or own/ended/unreadable custody).

Receipts bind sleep/pause identity, generation, attempt, source, runs and workspace; Restart rebinds before orphan recovery. Unconfirmed acceptance needs exact withdrawal before awake return (acceptance wins its race; unknown withdrawal holds interruptibly); readiness grants no release, Continue or child choice.

Ready tools and wakes expose exact question refs and update retained exposure after delivery (cold retries roll back); `dependency_held` shows once per stop/`root_resume_basis` without waking; `sleep_wake.py` records readiness off Q without HTTP. Returns observe without stopping (exact body custody keeps the actor over live/unsettled runs, granting no stopped-work resume or external-exit proof; untransferred writers hold; independent critics keep their controller), while money, fences, time, capacity and grants still bind.

Warm and lane-retaining cold sleeps refuse queued roots needing their lane; manual Restart/Panic hold sleep for Resume, ordinary cold sleep drops stale handoffs, ready cold sleep wakes unless held, and clock recovery matches task/attempt/grant/source without granting execution.

#### Monetary authority and projections

**Live global limit.** One resolver reparses saved settings on change (falling back uncached to env); workers refresh at start while live reads keep `TOTAL_BUDGET` current apart from planning thresholds (absent = default, non-positive = unbounded). Pre-load `OUROBOROS_REVIEW_RUN_CAP_USD` (isolated contributor review only) replaces saved budget for that tree (unreadable = zero).

`pricing.py` uses bounded catalog lookup (`llm_routing.attempt_pricing_fields`, no manual tables or fallback prices); unbound rows/empty pools stay unknown. Reserve and dispatch check settled spend (global binds `paid_admission` only; dispatched rows park only with saved work); holds/unresolved bounds are exposure so concurrent/late charges can overshoot. Unknown prices reserve None and settle from reported cost, an exact receipt or a DeepSeek attempt's own pinned catalog quote (`pricing_catalog.pin_tariff`; `/user/balance` supplies only the key's currency, and `_usage_settlement.py` prices only a USD key with complete usage inside the quote's off-peak or search terms), else non-final. `usage_admission.review_wave_admission` checks global/root/group for skill, plan, task and commit waves (session-only plans still check root/group; managed updates only record `managed_update_wave_estimate`); unpayable seats bypass without substitution and unpriced seats stay disclosed.

**Whole-work billing group.** `usage_admission.py` separates task/root/parent IDs from `billing_group_id`/`billing_group_limit_usd` in one transaction covering successors and original-root late work (Continue inherits `billing_group`, else earliest ledger authority, else `legacy_default`; `binding_axis=group`, pacing and strict Resume share it; only the group owner amends its cap; `task_money_snapshot` shows both axes). Unestablished authority refuses typed rather than faking zero/group, late overruns bar admission without promising a bill cap, non-task UI/marketplace contexts declare their role, and reservations keep applied global limit/source/revision.

`GET /api/tasks/{id}` derives `cost_breakdown` (own/child/unattributed, purpose/route, sessions, unknowns, finality) from the store with no persistence or third sum, omitting unreadable/unattributable ledgers. Physical review sends emit `llm_usage` by wave/slot (`review_records.resolve_review_wave`; skill seats use ledger rows, delegates observed provider/model). `state.json`, task results, `llm_usage`, `/api/state` and `/api/cost-breakdown` are compatibility projections; Drive state shows dated OpenRouter deltas, not `/status` warnings.
