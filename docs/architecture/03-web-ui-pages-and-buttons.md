# 3. Web UI Pages & Buttons

One build-free SPA serves desktop, browser, Docker, Telegram, phone and Linux fallback. The browser paints host-stamped placement, outcome, receipts and liveness; text, timing and client lists grant no authority.

### SPA shape and host bridges

The SPA is inspectable vanilla JavaScript (`web/index.html`, CSS, `web/modules/*`). `web/app.js` owns page/Project/mobile navigation; modules own presentation/disposers (DEVELOPMENT "UI resources carry a disposer"). Linux fallback is presentational; the owner's browser is outside process custody (§1). Rooms share one WebSocket; REST recovers durable truth (§4).

`MainApi` (`window.pywebview.api`, `launcher.py`) natively confirms runtime mode, reviewed-skill auto-grant and skill key grants; `launcher_background.DesktopApi` provides `panic_stop`, `request_attention`/`notify_owner`, `shell_info`, `request_native_notifications`, `show_native_notification` via `desktop_notifications.py`, `set_native_appearance` and `set_interface_size`. File/URL helpers: `download_file_to_downloads`, `open_file_with_default_app`, `open_external_url`, `save_bytes_to_downloads`. Loopback files need the server's own host/port and `/api/files/download`, `/api/extensions/...` or `/api/tasks/...`. `ui_helpers.js` detects each method for older shells (§2), falls back to file helpers or copy-link/toast and intercepts framed onboarding links (`OnboardingHostApi`). The Telegram proxy's `X-Ouroboros-Telegram-MiniApp: 1` has `server_web.make_index_page` include the Telegram SDK: presentation, not authentication.

### Navigation and shared UI contracts

The page's stored choice is the one appearance authority. Before CSS, `web/theme.js` reads client-local `ouroboros.theme` (light/dark/system), shared by same-origin windows. Settings/onboarding's `[data-theme-control]` has no `s-` field and posts nothing; `ouro:theme-changed` reports resolved palette changes only. Windows' top-level `set_native_appearance(theme,page,sequence)` keeps the newest call (`launcher_appearance.py`); dark-on-light/Windows10 pixels are unverified. macOS `launcher_window_chrome.py` reads `ouroboros-window-chrome` meta: integrated uses the transparent bar, real traffic lights and measured `data-window-chrome`/`--window-chrome-*` reserves. Undeclared pages get ordinary chrome without a bridge, so old or custom UIs still replace it. Light/Dark force window appearance; System inherits `prefers-color-scheme`.

`notifications.js` owns one live-only socket subscription outside rooms (DESIGN §9). `mainThreadAccepts` and lifecycle/`system_type` classify; the full registry resolves clicks, never numeric ranges/sidebar rows. Failed lookup keeps the view; Main transports stay Main. Fresh `shell_info().native_notifications` precedes live preferences and native dispatch. Definite failure plus a new positive permission/sound read permits the soft tone; submission proves no permission, unknown delivery stays quiet. Volume/Preview are client-local.

Iframes inherit no host tokens or stored choice; `render.appearance` declares their policy (CREATING_SKILLS). `webview.start(private_mode=False)` keeps storage pywebview otherwise erases at each opening. macOS also needs stable identity across source handoff (§2); ordinary-app and legacy Python profiles are never merged. Native Windows remains unqualified.

`pages.js` lists Main, Files, Skills, Widgets, Dashboard, Settings/About. `syncNavigationState()` owns page/Project/expansion/drawer; widths are owner-local. `#<page>` is read once, never written (no desktop address bar; Telegram loads `/`). Projects are panels, not routes, in the sole `<nav>`: keyed pointer/keyboard rows open/pin/rename/delete; `PROJECT_NAME_MAX` and lifecycle govern names; pins survive `/api/state` caps; deleting rooms cannot open until registry publication. `style.css` gives Main track 2 of 2, hiding retained `#divider`, unboxing `.sidebar-scroll`; panels overlay. Below `layout.js`'s switch, Main takes track 1, sidebar becomes a drawer, Project fills content. `layers.js` owns dismissal; `host_telegram.js` binds Telegram Back; `drawer_drag.js` speeds visible controls; `shell_motion.js`/`room_retire.js`/`motion.js` move between places (DESIGN §10).
