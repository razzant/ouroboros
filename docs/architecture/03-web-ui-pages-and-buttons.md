# 3. Web UI Pages & Buttons

One build-free SPA serves desktop, browser, Docker, Telegram, phone and Linux fallback. The browser paints host-stamped placement, outcome, receipts and liveness; text, timing and client lists grant no authority.

### SPA shape and host bridges

`web/app.js` owns SPA page/Project/mobile navigation; modules own presentation/disposers (DEVELOPMENT "UI resources carry a disposer"). Linux fallback is presentational; owner browsers are outside process custody (§1). Rooms share one WebSocket; REST recovers durable truth (§4). `utils.loadVersion` reads sidebar/About versions from health at startup/socket open: retained pages outlive cores.

`MainApi` (`window.pywebview.api`, `launcher.py`) natively confirms runtime mode, reviewed-skill auto-grant and key grants. `launcher_background.DesktopApi`: `panic_stop`, `request_attention`/`notify_owner`, `shell_info`, `request_native_notifications`, `show_native_notification` (`desktop_notifications.py`), `set_native_appearance`, `set_interface_size`. File/URL helpers: `download_file_to_downloads`, `open_file_with_default_app`, `open_external_url`, `save_bytes_to_downloads`; loopback files require our host/port and `/api/files/download`, `/api/extensions/...` or `/api/tasks/...`. `ui_helpers.js` detects older-shell methods (§2), falls back to file helpers/copy-link/toast and intercepts framed-onboarding links (`OnboardingHostApi`). Telegram proxy `X-Ouroboros-Telegram-MiniApp: 1` makes `server_web.make_index_page` include its SDK: presentation, never authentication.

Live Conversation (§13; DESIGN “Voice controls”) owns catalog-based Calls (beta) settings, local devices and empty-Send Talk. Server offers/vision use catalogs and grants. Calls keep hidden-room/document leases; dictation releases on hide. End/Stop/Panic/pagehide/device loss/off/unload end calls; failed reads do not. Its LiveHost driver greets once, renews quietly, records owner/Presence languages and ends after goodbye playback via call-local tools.
