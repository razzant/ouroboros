### 11.2 What is NOT frozen (intentionally)

`ToolContext` is mutable beyond its protocol minimum. Pins lock shape keys, not WS/HTTP values; frontmatter, not `SKILL.md` bodies. State/queue writers stamp `_schema_version: 1` while readers accept unstamped v0; `current.sqlite` task rows use `task_result_schema.py` admission (§11.4).

### 11.3 What to do when extending

Extend owners (§11.1) compatibly with contract/parity tests (CHECKLISTS 23, `gateway_parity`). Removal needs a versioned successor and release migration note. Current window: §11.4; history: release ledger.

### 11.4 Recent ABI Retirements

- **ABI 7.0** is one deliberate window (breaks land together, not one per minor); read-only `scripts/rc_audit.py` scans third-party installs across six incompatibility classes pre-upgrade.
- Record passport 2: `record_contract_version: 2` rows read nullable token counters from `usage.reported_tokens`, never billing counters (any unknown part nulls sums/cache derivatives); unstamped zeros stay ambiguous (`record_contract.LEGACY_RULE`, not `$0`).
- Settings & review pool: `load_settings` strips disk `settings_defaults.RETIRED_SETTING_KEYS` on every load and notifies once per key set (one process log and System row; `state.json:retired_settings_notified`), ignores `RETIRED_COMMA_LIST_SETTING_KEYS` envs (`OUROBOROS_REVIEW_MODELS`, `OUROBOROS_SCOPE_REVIEW_MODELS`, `OUROBOROS_SCOPE_REVIEW_MODEL`, `OUROBOROS_REVIEW_ROUTES`, `OUROBOROS_SCOPE_REVIEW_ROUTES`, `OUROBOROS_ADVISORY_REVIEW_ROUTE`) for Settings → Agents / factory rows (§7), and migrates disk `REVIEW_POOL_MIGRATED_SETTING_KEYS` (`OUROBOROS_REVIEWER_SLOTS` + §7 surface keys) into `OUROBOROS_SUBAGENTS` reviewer rows (`GET /api/review-pool`; unconvertible input stays intact with error, first save writes `state/review_migrations/` + `state.json:review_pool_migrations`, first boot reports). Native review keeps deadline/wallet bounds, result review deadline less finalization grace, observability stays intact, consciousness uses Main bounds + `OUROBOROS_EFFORT_MAX`.
- Gateway & Storage: `api_v1`, `cost_usd`/`cost_usd_with_children`, `telegram_chat_id`, `project_last_viewed`/`project_hidden` retire (stored rows read tolerantly; `UiPreferencesResponse` 400s unknown keys; `task_bindings` drops `project_name`); `StorageMeasurement`/`StorageCategory` and `measurement`/`measuring` become `StorageCount`/`StoragePlace`, `count`/`counting`, `error`, `volume`, `retention_days`, `free` (§4).
- Skills sources (`GATEWAY_ABI_VERSION` unchanged): retires `/api/marketplace/ouroboroshub/*`: `catalog`, `preview/{slug:path}`, `install`, `update/{name}`, `uninstall/{name}`, `publication/{name}/clear`; `HubCatalogResponse`, `HubPreviewResponse`, `MarketplaceInstallRequest.adopt`/`expected_content_hash`, and `MarketplaceInstallResponse` fields `code`, `adopted`, `pre_adopt_retained`, `retention_error`, `live_content_hash`, `reason`, `rolled_back`, `rollback_errors`, `official_hub_verified`. Successors: `/api/skill-catalog*`, `/api/skills/{name}/update`, `/api/skills/{name}/uninstall`, `/api/skills/{skill}/publication/clear`, and digest-bound `install.official`. `GET /api/marketplace/ouroboroshub/installed` (`MarketplaceInstalledResponse`) stays frozen; CLI `marketplace ouroboroshub` aliases `sources`.
- Plugin ABI & task rows: hash-bound PASS extensions keep loading (§11.1 `PluginAPI`); durable task writes stamp `_schema_version: 1`, `task_results/<id>.json` is import/export only, quarantined inadmissible rows (log-only) hold ids occupied.
