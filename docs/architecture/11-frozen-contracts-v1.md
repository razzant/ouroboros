### 11.2 What is NOT frozen (intentionally)

`ToolContext` stays mutable; its protocol pins only the minimum. Shape keys, not raw WebSocket/HTTP values, and frontmatter, not the SKILL.md body, are pinned. State and queue writers stamp `_schema_version: 1`; readers tolerate unstamped legacy version 0. Task documents in `current.sqlite` use `task_result_schema.py` admission (§11.4).

### 11.3 What to do when extending

Extend the frozen owner (§11.1) compatibly; add contract/parity tests (CHECKLISTS 23, `gateway_parity`). Removal needs a versioned successor and release migration note. §11.4 covers the current upgrade window; the release ledger keeps history.

### 11.4 Recent ABI Retirements

- Record passport 2: `record_contract_version: 2` rows carry nullable token counters read from `usage.reported_tokens`, never billing counters (a sum or derived cache field is null once a part is unknown); unstamped zeros stay ambiguous (`record_contract.LEGACY_RULE`).
- **ABI 7.0** is one deliberate window: breaks land together, not one per minor. `scripts/rc_audit.py`, the read-only pre-upgrade scan of a third-party install, names every incompatibility across its six classes, reading the key lists at run time.
- Settings: `settings_defaults.RETIRED_SETTING_KEYS` owns the removed-key list; `load_settings` strips it from disk and notifies once per key set (one process log and System row; `state.json:retired_settings_notified`). Native review retains deadline/wallet bounds and a result review the deadline less the finalization grace; observability stays preserved; consciousness uses Main's bounds and `OUROBOROS_EFFORT_MAX`. `RETIRED_COMMA_LIST_SETTING_KEYS` envs (`OUROBOROS_REVIEW_MODELS`, `OUROBOROS_SCOPE_REVIEW_MODELS`, `OUROBOROS_SCOPE_REVIEW_MODEL`, `OUROBOROS_REVIEW_ROUTES`, `OUROBOROS_SCOPE_REVIEW_ROUTES`, `OUROBOROS_ADVISORY_REVIEW_ROUTE`) are ignored: select reviewers in Settings → Agents, else factory rows apply (§7).
- Review pool: `REVIEW_POOL_MIGRATED_SETTING_KEYS` (a `RETIRED_SETTING_KEYS` subset) migrates `OUROBOROS_REVIEWER_SLOTS` and §7's listed surface keys into `OUROBOROS_SUBAGENTS` reviewer rows. Only disk settings migrate; unconvertible input stays intact with its error. First save preserves `state/review_migrations/` and `state.json:review_pool_migrations`; first owner boot reports it. One list serves review (`GET /api/review-pool`); owners, factory fallback, receipts and ignored-environment notice: §7 Reading and writing the settings document and Review pool.
- Gateway envelopes: the `api_v1` re-export and the `cost_usd`/`cost_usd_with_children`, `telegram_chat_id`, `project_last_viewed`/`project_hidden` aliases are gone; stored rows still read tolerantly, and `UiPreferencesResponse` answers 400 on an unknown key.
- Storage: `StorageMeasurement`/`StorageCategory` and `measurement`/`measuring` give way to `StorageCount`/`StoragePlace`, `count`/`counting`, `error`, `volume`, `retention_days`, `free` (§4).
- Skills sources v4 retires `/api/marketplace/ouroboroshub/*`: `catalog`, `preview/{slug:path}`, `install`, `update/{name}`, `uninstall/{name}`, `publication/{name}/clear`; `HubCatalogResponse`, `HubPreviewResponse`, `MarketplaceInstallRequest.adopt`/`expected_content_hash`, `MarketplaceInstallResponse` fields `code`, `adopted`, `pre_adopt_retained`, `retention_error`, `live_content_hash`, `reason`, `rolled_back`, `rollback_errors`, and `official_hub_verified`. Successors: `/api/skill-catalog*`, `/api/skills/{name}/update`, `/api/skills/{name}/uninstall`, `/api/skills/{skill}/publication/clear`, and digest-bound `install.official`. `GET /api/marketplace/ouroboroshub/installed` remains frozen (`MarketplaceInstalledResponse`); CLI `marketplace ouroboroshub` aliases `sources`. This retirement leaves `GATEWAY_ABI_VERSION` unchanged.
- Plugin ABI: an existing hash-bound PASS keeps loading; manifest negotiation and defaults: §11.1 (`PluginAPI`).
- Durable task rows: writes stamp `_schema_version: 1`; `task_results/<id>.json` is import/export, not current authority. Inadmissible rows are quarantined (log-only), never converted, and keep their ids occupied.
