# Support

Choose the route that best matches what you need:

| Need | Where to go |
|------|-------------|
| A question about setup, behavior, or using Ouroboros | [GitHub Discussions](https://github.com/razzant/ouroboros/discussions) |
| A reproducible defect | [Open a bug report](https://github.com/razzant/ouroboros/issues/new?template=bug_report.yml) |
| A scoped product or capability proposal | [Open a feature request](https://github.com/razzant/ouroboros/issues/new?template=feature_request.yml) |
| A possible vulnerability | Follow [SECURITY.md](SECURITY.md) and report it privately |
| A code or documentation contribution | Follow [CONTRIBUTING.md](CONTRIBUTING.md) |

For technical questions, include the platform, installation method, Ouroboros version, what you were trying to do, and the smallest useful error or log excerpt. Remove credentials, tokens, private paths, and unrelated runtime data before posting.

Please use one thread or issue per problem. A clear reproduction is more useful than a large unfiltered log dump.
