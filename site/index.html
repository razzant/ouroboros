It remembers.
In its own words.

Open conversations stay verbatim; closed matters become pages it wrote, with the quotations checked. Knowledge sits on shelves, notes link to each other, and one memory spans every room and channel.

It thinks between
your messages.

Advises, acts or evolves: you set the level. It wakes at night on its own schedule, reads what arrived, prepares, and tells you only what matters.

Make it
a skill.

“Make me a Doom-style shooter I can play right here.” Done, playable in the chat card. A chart becomes a widget, a 43-paper research becomes a table, an image gets drawn. Whatever it makes, one click keeps it.

It rewrites
its own code.

Evolution campaigns change its implementation: code, prompts, tools, memory. Every change is reviewed by other models, checked, and kept in Git history. The constitution it wrote for itself sets the limits.

Any model.
Your accounts.

For the mind: Codex, Claude, Gemini, Grok, DeepSeek, OpenRouter or a local GGUF model. For the coding helpers: Codex, Claude Code, Cursor and Antigravity subscriptions. Several keys per provider, exact pins, processing tiers, costs and cache in plain numbers.

Everywhere
you are.

One agent and one memory across the desktop app, the phone, your chat apps and the terminal. The interface translates itself into your language.

  • Speaks your languageThe interface translates itself; your words stay as written.
  • Draws imagesMakes and edits pictures with gpt-image-2.
  • Uses your computerClicks, types and reads the screen on macOS and Windows.
  • BrowsesA built-in browser for research and checks, with sources kept.
  • Keeps a scheduleA digest every Friday, a check every night: each run reports what it did.
  • Shares an answerAs text, a picture or an offline page.
  • Safety SupervisorA second model checks risky calls before they run.
  • Android, experimentallyThe whole runtime on a Magisk-rooted ARM64 phone.

Don't like a part?
Swap it. It's all plugins.

The core stays small. Skills, widgets, connectors, voice engines, review panels and MCP tools are plugins with reviewed manifests: install one from OuroborosHub, write your own in an afternoon, or ask Ouroboros to write it for itself. Your install stays yours across updates.

  • SkillsTools, workflows and instructions it learns to use.
  • WidgetsLiving cards on its board, from a chart to a game.
  • ConnectorsSlack, Telegram, email, GitHub: the places where it is a colleague.
  • Voice enginesGemini Live, Grok Voice, OpenAI realtime, or yours.
  • Review panelsWhich models judge the plan and the result.
  • MCP toolsAny server, loaded when a task needs it.
