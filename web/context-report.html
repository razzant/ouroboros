How to make a report
  1. Take the task's full ID from Dashboard › Logs: open the task's entry, then one of its events. The record under the event shows it as subagent_task_id when the event has one, else as task_id. The ID beside a Logs entry is cut to 8 characters, and a Context Lens chart is named by a hash; neither is a full task ID.
  2. In a terminal, from a separate source checkout of this version (never the running one), list that task's attempts, newest first: python -m ouroboros.context_attempt_reader --data-root DATA TASK_ID, where DATA is this installation's data folder.
  3. Write one attempt's report into a private folder that is not synced: python -m ouroboros.context_attempt_reader --data-root DATA TASK_ID --attempt ATTEMPT_ID --report > report.json
  4. Open that file here. Each attempt has its own report, also when two attempts sent the same request.

Private text can remain. Only known secret patterns are masked, so names, messages and file paths stay readable. Keep this file on this computer; it is not meant to be forwarded automatically.
